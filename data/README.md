# data/

地図に描画するデータファイルを格納するディレクトリです。

## 想定するファイル形式

| 形式 | 用途 |
|------|------|
| GeoJSON (`.geojson`) | ポイント・ライン・ポリゴンなどの地物データ |
| CSV (`.csv`) | 緯度経度を含む場所リスト |
| GPX (`.gpx`) | GPS トラックログ |

## ファイル命名規則

```
{種別}_{説明}.geojson
例:
  places_visited.geojson   # 訪れた場所
  places_want_to_go.geojson # 行きたい場所
```

## 注意事項

- 個人情報（自宅住所・プライベートな場所）を含むファイルは `.gitignore` に追加してください
- 大容量ファイル（目安: 10MB 以上）は Git LFS の利用を検討してください
